# Archived: first iteration (Riverton four-day week)

This was the first design, built in Steps 0–4 (see `docs/PLAN.md` in this folder). It
was replaced by the atomic-point design in `docs/design_spec.pdf`. We kept these files
because they record how the design changed and what we measured along the way. The
embedding diagnostics here (Step 4) motivated several changes to the new design.

These files are not imported by the current code, and their tests are not collected.
